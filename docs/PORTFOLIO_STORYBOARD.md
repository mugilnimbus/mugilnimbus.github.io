# Portfolio storyboard

## The series

```text
Intro: greeting -> physics + AI (+ some creativity) = one point -> the point opens into project stars
        |
        v
Trailer (four projects, about a minute)   or   Episode 1   or   any star
        |
        v
Episode: question -> one object -> beat one -> beat two -> project line
        |                                   |
        v                                   v
Next episode plays by itself        Detailed view / Read the full story / View source
```

## One episode

| Beat | On stage | Words |
| --- | --- | --- |
| Question | Empty stage | A problem the visitor may have felt, written word by word |
| Object | One line drawing builds itself | None |
| First beat | Part of the drawing is found or revealed; the first handwritten note | One sentence |
| Second beat | The drawing acts; the second note; the first fades | One sentence |
| Closing line | Whole drawing; the detail button lights up | The project's line |
